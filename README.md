# Reading Diary

Личный читательский дневник в браузере: библиотека, прогресс, таймер чтения,
статистика, цель и заметки. Одна ссылка, один интерфейс на iPhone и Android —
ничего устанавливать не нужно.

**Открыть:** https://zakhvatov.github.io/reading_diary/ (появится после первого деплоя)

## Что внутри

- полки «Хочу прочитать», «Читаю», «Прочитано», «Не дочитал»;
- добавление книги вручную, поиском или по ISBN;
- таймер чтения и ручные сессии;
- календарь, статистика, годовая цель и серия дней;
- дневник с заметками и цитатами;
- экспорт и импорт резервной копии.

## Данные

Приложение работает без аккаунта и без сервера. Книги, сессии и заметки
хранятся только в браузере на вашем устройстве (IndexedDB). На GitHub не
уходит ничего, кроме кода приложения. Резервная копия — обычный файл, который
можно сохранить в Files или Drive.

## Стек

Vite, React, TypeScript, Tailwind CSS, Dexie, `vite-plugin-pwa`.
Хостинг — GitHub Pages, публикация через GitHub Actions.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

Проверка сборки под GitHub Pages:

```bash
BASE_PATH=/reading_diary/ npm run build
```
